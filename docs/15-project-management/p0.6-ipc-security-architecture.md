## 1. Executive summary

```
XSS / compromised renderer
  → window.electronAPI (allowlisted but privileged)
```

4. Retained desktop-bridge IPC: backup/restore (PIN), Master PIN status, app info, status, updates.  
5. Tests: `tests/electron-ipc-phase-b1.test.ts` · `npm run test:electron-ipc-b1` · wired into `test:security`.

**Still open (B2):** `restart-and-install` remains unauthenticated (download-flag only).

**IPC SECURITY (post-B1):** **GREEN WITH HARDENING** for B1 surface; overall P0.6 remains incomplete until B2.

## 2. Current IPC architecture (post-B1)

```
Renderer (untrusted; sandbox:true)
  ├─ fetch → Express API (JWT + RBAC + optional Master PIN)  ← preferred control plane
  └─ window.electronAPI → preload allowlist → ipcMain.handle  ← minimal desktop bridge

Main process
  ├─ ipc.ts: backup-database, restore-backup (hardened), master-pin-status, get-app-info
  ├─ index.ts: get-status, get-update-status, check-for-updates, restart-and-install (B2 auth pending)
  ├─ Menu / updater → webContents.send (push; navigation nudges)
  └─ SQLite / fs / safeStorage / autoUpdater / BrowserWindow
```

**Principle:** Treat the renderer as hostile. Preload allowlisting and UI visibility are **not** authorization.

```
  ├─ Steal localStorage.token → full HTTP API as victim role
```

## 6. Restore-path model (IMPLEMENTED)

| Step | Before B1 | After B1 |
|------|-----------|----------|
| Auth | `authorizeMasterPin` | Unchanged |
| Managed restore | Optional absolute `presetBackupPath` | Optional managed `fileName` under `userData/backups` via `resolveManagedBackupPath` |
| External restore | Same absolute path path | OS picker only; path validated by `validateExternalRestorePath` |
| Guards | Symlink / live-DB in `materializeRestoreSource` | Plus IPC-boundary: regular `.db` file, no symlink/dir, not live DB |

**Helpers:** `main/security/restore-path.ts`  
**Settings UI:** passes `backup.fileName`, not `backup.path`  
**Preload signature:** `restoreBackup(pin?, fileName?)` — never absolute filesystem paths from renderer.
