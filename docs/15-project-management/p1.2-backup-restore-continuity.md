## Tested recovery path

1. Seed realistic POS fixture (orders, bills, partial payment, refund, closed shift, day-close, audits) + `jwt-secret.enc`
2. `createBackup()` → self-contained `.db` with `_flo_meta`
3. Assert JWT secret bytes **not** in backup; `.enc` unchanged
4. Reject corrupt backup while live DB healthy
5. Reject future-schema backup while live DB healthy
6. Close + delete live `flo.db` (+wal/shm)
7. `initDatabase()` on missing file → **empty schema (REC-01)** — documented
8. `restoreBackup(path, true)` → financial state returns
9. Re-assert FIN-01 (over-collect ₹401 rejected; ₹400 allowed → gross 1000 / net 800)
10. Scenario A: `.enc` intact → `secure`
11. Scenario B: delete `.enc` → `recovery_required`; `initializeJWTSecret` fails closed (no silent regen)

---

## Same-machine behavior (Scenario A)

- Restore replaces SQLite business data
- `jwt-secret.enc` remains outside backup and is **not** replaced/removed by restore
- Status stays `secure`; same secret bytes after cache clear
- No `jwt_secret` row in restored SQLite
- Existing tokens remain valid while secret unchanged (architecture unchanged)

---

## New-machine behavior (Scenario B)

- Restored DB without decryptable `.enc` → `recovery_required`
- No silent JWT regeneration
- Recover still requires existing owner + Master PIN API (no new recover UI in this milestone)
- Pilot ops: DB backup alone is not full DR without Master PIN knowledge

---

## Corrupt-backup behavior

- Invalid/non-SQLite bytes → `restoreBackup` returns `{ success: false, error: ... }`
- Live DB is **not** replaced
- IPC path already rejected missing metadata via `getSchemaVersionFromBackup` → `null`

## Architecture reference (unchanged)

### Backup

- `createBackup` / `createBackupUnlocked` → full SQLite `.db` + `_flo_meta`
- Excludes `jwt-secret.enc`, `master-pin.enc`, Drive tokens
- Managed path: `{userData}/backups/`

### Restore

- IPC Master PIN + B1 path harden
- Same schema → direct replace; older → data-only
- Live-protected settings / credentials / outboxes / revocations merged
- SQLite `jwt_secret` stripped; JWT caches cleared on IPC restore
