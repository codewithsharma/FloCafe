## 1. Executive summary

P0 Electron/IPC/JWT/LAN hardening delivered a **defensible staff-LAN pilot baseline**. Renderer sandbox, fail-closed navigation, shrink+allowlisted desktop IPC, JWT-gated updater install, mode-gated binds, and safeStorage JWT secrets are in place and test-gated.

**One genuine money-integrity defect was found at audit time (FIN-01) and is now CLOSED:** after partial tender + partial refund, payment eligibility incorrectly used net `paid_amount`. Fix: collectible outstanding = `bill_total − gross_successful_tender`. Tests in `integration-refunds` §19–21.

Dominant residual attack class is unchanged by Electron hardening:

```
XSS (CSP allows 'unsafe-inline')
  → steal localStorage JWT
  → authenticated HTTP API as that role
```

IPC alone is no longer the primary wipe/mutate plane for unauthenticated XSS.

### Final verdict

# **GO WITH CONDITIONS**

Safe for **controlled café pilots** if operational conditions below are enforced. FIN-01 (partial-pay + refund over-collection) is **CLOSED**.

## 2. Current architecture (security-relevant)

```
Renderer (sandboxed, contextIsolated, nodeIntegration:false)
  ├─ fetch → Express :3001 (JWT + RBAC + optional Master PIN)  ← SoT for business ops
  └─ electronAPI → preload allowlist → 8 ipcMain.handle        ← desktop bridge only

Main
  ├─ SQLite (better-sqlite3), printers, safeStorage, autoUpdater

  └─ jwt-secret.enc (safeStorage); not in SQLite/Drive backups
```

## 11. Pilot conditions (mandatory for GO WITH CONDITIONS)

1. **`network_mode=localhost`** unless multi-device required; then **staff-only** SSID/VLAN — **never guest Wi‑Fi**.  
2. **Master PIN set** and known only to owner/manager; practice backup/restore once.  
3. **Packaged builds only** for pilots; **Windows pilots require signed artifacts**.  
4. ~~**FIN-01**~~ **CLOSED** — collectible outstanding = bill total − gross successful tender.  
5. Regular local (and optional Drive) backups; treat backups as sensitive PII.  
6. Linux: ensure desktop keyring so `safeStorage` is available.  
7. Owner/manager account hygiene; rotate JWT secret (Master PIN) if compromise suspected.  
8. Do not treat Gross−Refunds dashboards as cross-day GAAP until REP-01 understood.
