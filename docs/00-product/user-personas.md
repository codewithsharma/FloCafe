# User Personas

## CURRENT STATE personas (from implemented roles)

### Maria — Owner

- Sets up business, tax, staff, printers
- Reviews daily sales on dashboard
- Manages backups and optional cloud
- **Uses:** Settings, reports, staff, database tools

### Carlos — Manager

- Opens/closes service, handles exceptions
- Approves voids with PIN
- **Uses:** POS, orders, manager PIN prompts

### Priya — Cashier

- Takes counter and takeaway orders
- Processes payments and prints receipts
- **Uses:** POS primary screen

### James — Waiter

- Takes table orders from floor tablet
- **Uses:** Server App (`/server-standalone`, port 3003)

### Lin — Chef

- Views and updates kitchen queue
- **Uses:** KDS standalone or embedded
